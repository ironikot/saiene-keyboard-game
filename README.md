# 再エネ打（saiene-da）

流れてくる**再生可能エネルギー用語**をローマ字でどんどん打って「発電」していくタイピングゲームです。
「寿司打」でおなじみの〈ベルトコンベアで流れてくるお題を打ち切る〉という遊び方を踏襲しつつ、
**コード・素材はすべてオリジナルで自作**し、お題を再エネ用語に差し替えています。HTML / CSS / 素の JavaScript のみで動きます。

> 注：寿司打そのもののコードや画像・音などの素材は一切使っていません。タイピングゲームという
> ジャンル（仕組み）を参考にしたオリジナル実装です。

## あそびかた

1. `index.html` をブラウザで開く。
2. コースを選ぶ（お手軽 / お勧め / 達人 / 事業用語）。
   - **事業用語コース**は脱炭素・再エネ調達まわりの事業用語（公開情報）から出題します。
3. カウントダウンのあと、ベルトコンベアでお皿が流れてきます。
4. 画面下に出るローマ字どおりにキーボードで入力。お皿が左の工場（🏭）に届く前に打ち切れば「発電」成功。
5. 取り逃すと失点。最後に発電量・正確率・速度・ランクが出ます。

- **入力は半角英数（IME はオフ）**で行ってください。
- ローマ字は複数表記に対応：`し=shi/si`、`じゃ=ja/jya/zya`、`ふ=fu/hu`、`つ=tsu/tu` など。
- 促音 `っ`（例 `gakkou`/`galtukou`）、撥音 `ん`（`n`/`nn`）、長音 `ー`（`-`）にも対応。

## ローカルでの起動

ただ `index.html` をダブルクリックで開くだけでも動きます。
サーバー経由で確認したい場合は、付属の簡易サーバーを使えます。

```bash
node server.js
# → http://localhost:4173 を開く
```

（Python 派なら `python3 -m http.server 4173` でも可）

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面構成（スタート / ゲーム / リザルト） |
| `css/style.css` | 見た目（空・ベルトコンベア・お皿などの演出） |
| `js/romaji.js` | ローマ字入力エンジン（かな→ローマ字候補、1打ごとの判定） |
| `js/words.js` | 再エネ用語データ（コース別の語彙） |
| `js/audio.js` | 効果音（WebAudio で合成。外部素材なし） |
| `js/game.js` | ゲーム本体（進行・スコア・演出の制御） |
| `server.js` | ローカル確認用の簡易静的サーバー |

## カスタマイズ

- **お題を増やす**：`js/words.js` の `EASY` / `NORMAL` / `HARD` / `BUSINESS` に
  `{ label: "見出し", reading: "よみがな", icon: "絵文字" }` を追加するだけ。
  - `BUSINESS` は公開情報（JERA Cross 公式サイト由来）の事業用語プール。
  - `reading` は打鍵対象の読み（ひらがな / カタカナ）。
  - 注意：`ん` の直後に母音・な行・や行が来る読み（例「ぼんにゅう」）は
    ローマ字判定が曖昧になるため避けています。
- **難易度（流れる速さ）**：`js/words.js` の `COURSES.*.speed` を調整（大きいほど速い）。
- **目標発電量**：`COURSES.*.power`（kWh）を調整。

## スコアの考え方

- **発電量(kWh)** ＝ 正打1キー 30 × コンボ倍率 ＋ クリア1問 150 × コンボ倍率 ＋ スピードボーナス
- **コンボ**：ミスせず打ち続けると増加。10で×1.5、20で×2、40で×3。ミス・取り逃しでリセット。
  - 20コンボごとにお皿が押し戻される（実質 +1.2秒）。30コンボで**フィーバー**演出。
- **スピードボーナス**：速く打ち切るほど加算（残り時間に比例・最大300 kWh）。
- コースの**目標 kWh** を超えれば「黒字」、届かなければ「赤字」。
- **ランク**は平均打鍵速度（打/秒）で決定（みならい → … → グリッドマイスター）。
- **ランキング**：コース別ベスト5を端末内（localStorage）に保存。サーバーには何も送りません。
- **CO₂削減量**は発電量からのざっくり換算（演出用）。
